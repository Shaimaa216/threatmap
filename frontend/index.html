ABOUT THREATMAP

Intelligent IP Threat Intelligence & Network Analytics Platform

ThreatMap turns IP addresses into understandable security context using the official IP2Location.io API as its core intelligence source.

Core data

Geolocation, ISP, ASN, AS information, domain, usage type and proxy/security indicators returned by IP2Location.io.

Risk methodology

The ThreatMap Risk Score is an application-level heuristic. It is not a definitive statement that an IP is malicious.
