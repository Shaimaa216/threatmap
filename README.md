# ThreatMap

### Intelligent IP Threat Intelligence & Network Analytics Platform

> Turn IP addresses into actionable security insights.

ThreatMap is a web-based IP threat intelligence and network analytics platform that transforms IP addresses into useful security and network insights.

The platform uses **IP2Location.io** as a core data source to analyze IP addresses, visualize their geographic and network information, and generate an application-level risk assessment.

## Features

-  IP address analysis
-  IP geolocation
-  Interactive map visualization
-  ISP and ASN information
-  Proxy and security analysis
-  ThreatMap Risk Score
-  Bulk IP analysis using CSV
-  Analysis history
-  Security and network dashboard
-  Responsive web interface

## ThreatMap Risk Score

ThreatMap calculates an application-level risk score from **0 to 100** based on available IP2Location security and network information.

| Score | Risk Level |
|------:|------------|
| 0–29 | Low |
| 30–59 | Medium |
| 60–100 | High |

The ThreatMap Risk Score is a heuristic generated by the application. It does not definitively classify an IP address as malicious.

IP2Location.io is a core component of ThreatMap.

The application uses IP2Location data to obtain IP geolocation, network information, and available security-related information.
